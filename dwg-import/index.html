Convertisseur DWG → DXF

Outil séparé pour MiniCAD — convertit un fichier .dwg en .dxf dans le navigateur, sans envoi sur un serveur. Ouvrez ensuite le .dxf obtenu dans MiniCAD (📂 Ouvrir).
